# 밤숲 동물과 실시간 음성 대화 · 배경음악 설계

상태: 사용자 “구현해줘” 승인 후 코드 구현 및 로컬/모의 검증 완료. API 키 미설정으로 실제 음성 왕복은 미확인.

## 목표와 승인된 범위

관객이 사슴 또는 토끼를 선택해 한국어로 실시간 대화하며 밤숲을 감상한다. 동물이 답할 때 움직임과 빛이 음성 크기에 반응한다. 잔잔한 배경음악을 재생하며 대화 중에는 작아진다. 사용자가 2026-10-12 제안 구성에 “오케. 진행해줘”로 승인했다.

기존 밤숲 화면, 클릭 효과, 움직임 줄이기, 키보드 접근, 전체 화면과 우측 아래 `made by Gerardo 2026.10.12`는 유지한다. 이전 사양의 무음·외부 API 제외 조건은 이번 사용자 요청 범위에서 변경한다. 온라인 배포는 포함하지 않는다.

## 관객이 사용하는 흐름

1. 화면 아래 `동물과 대화`를 누르면 작은 대화 패널이 열린다. 패널에서 사슴/토끼 선택, 상태, 짧은 자막, 대화 시작/종료와 마이크 음소거를 제공한다. 동물 클릭도 대화 상대 선택에 반영하되 기존 시각 효과는 유지한다.
2. `대화 시작`을 눌렀을 때만 마이크 권한을 요청하고 AI 음성 연결을 시작한다. 화면에는 AI와의 대화임을 표시한다.
3. 사슴은 차분하고 다정한 숲 안내자, 토끼는 밝고 호기심 많은 친구로 짧게 한국어로 답한다. 사슴은 cedar, 토끼는 marin 음성을 사용한다. 관객이 다시 말하면 기존 답변을 중단하고 새 발화를 듣는다.
4. `연결 중`, `듣는 중`, `답하는 중`, `마이크 꺼짐`, `연결 종료` 상태를 구분한다. 자막은 현재 답변 중심으로 표시하고 파일에 저장하지 않는다.
5. 다른 동물로 바꾸면 현재 연결을 종료하고 새 동물의 세션을 시작한다. 연결 중 변경·종료는 오래된 비동기 응답을 무효화한다. 이전 대화는 자동으로 다른 동물에게 전달하지 않는다.
6. `종료`, 페이지 떠남, 탭 숨김에서는 마이크 트랙과 연결을 정리한다. 다시 열었을 때 관객이 명시적으로 재시작한다.

## 배경음악

- Web Audio로 직접 구성한 느린 앰비언트 화음과 드문 종소리를 사용한다. 외부 음원 다운로드와 음악 생성 API는 필요 없다.
- `음악 켜기/끄기` 및 볼륨 조절을 제공한다. 브라우저 재생 정책에 맞춰 관객의 버튼 조작으로 시작하며 자동 재생 성공을 가정하지 않는다.
- 대화 연결부터 종료까지 선택한 음악 볼륨의 약 20%로 부드럽게 낮춘다. 종료하면 사용자가 설정한 볼륨으로 복원한다. 사용자가 껐던 음악을 자동으로 켜지 않는다.
- 음악용 오디오 그래프와 음성 재생 경로를 분리한다. 음악은 마이크 입력으로 직접 혼합하지 않는다. 마이크에는 브라우저의 echoCancellation/noiseSuppression을 요청한다.
- 음악 중지와 탭 숨김 시 노드/스케줄러를 정리하거나 중단한다. 켜기를 반복해도 음악이 중복 재생되지 않는다.

## 연결 구조

현재 정적 HTML/CSS/JS에 다음 모듈을 추가한다. 프레임워크 전체 전환이나 빌드 단계는 도입하지 않는다.

| 구성 | 책임 |
| --- | --- |
| server.mjs | Node.js 로컬 서버, 허용된 정적 파일 제공, API 구성 확인 및 WebRTC 연결 중계 |
| voice.js | 마이크/연결 수명 관리, 동물 선택, 음성 재생과 이벤트/자막, 음량 분석 |
| music.js | 앰비언트 생성, 음악 재생·볼륨·대화 중 감쇠 |
| night.js 수정 | 선택된 동물의 말소리 크기를 기존 움직임/빛에 반영 |
| index.html / styles.css 수정 | 음성 패널과 음악 조작부, 모바일·전체 화면 배치 |
| .env.example / .gitignore / README.md | 키 설정 예시, 비밀 파일 제외, 실행 안내 |

- 서버 기본 주소는 `http://127.0.0.1:8766`으로 하여 기존 8765 미리보기 프로세스와 충돌하지 않는다.
- `OPENAI_API_KEY`는 서버 환경에만 저장한다. 모델은 `OPENAI_REALTIME_MODEL`로 바꿀 수 있게 하고 기본값은 공식 Realtime 가이드의 `gpt-realtime-2.1`을 사용한다. 실제 계정 접근은 실연결 때 확인한다.
- 브라우저가 SDP offer와 허용된 동물 ID를 서버에 보낸다. 서버는 동물별 지침/음성 설정과 SDP를 `POST https://api.openai.com/v1/realtime/calls`에 보내고 SDP answer를 브라우저에 반환한다.
- 브라우저 WebRTC 미디어 트랙으로 마이크와 답변 음성을 전달하며, 데이터 채널로 준비 상태·발화·응답/자막 이벤트를 수신한다. 음성이 준비되기 전에 연결 완료로 표시하지 않는다.
- 세션은 audio 출력 및 발화 감지/중단 기능을 사용한다. 서버는 동물별 설정을 선택하며 클라이언트가 API 키나 임의 업스트림 주소를 지정하지 않는다.
- `/api/config`는 설정 여부만 반환한다. `/api/session`은 동물 ID와 SDP를 검사하고 같은 origin의 요청만 허용한다. 정적 파일은 허용 목록으로 제한하며 `.env`, `.git`, 서버 코드와 작업 기록은 제공하지 않는다. 요청 크기·동시 초기화·응답 대기시간에 상한을 둔다.
- 실제 음성 대화에는 인터넷, 사용 가능한 OpenAI API 키와 사용량 과금이 필요하다. 코드 작성/로컬 모의 검증과 실제 유료 API 검증은 결과를 구분한다.

## 동물 표현과 접근성

실제 출력 음성의 크기를 AnalyserNode로 읽어 선택된 동물의 작은 고개 움직임과 후광 강도에 연결한다. 기존 2D 자산을 이용하며 정교한 입모양 립싱크나 3D 턱 움직임을 약속하지 않는다.

움직임 줄이기에서는 기존처럼 이동 애니메이션을 멈추고, 음성 상태는 텍스트와 정적 강조로 표시한다. 음성·음악 자체는 별도 조작한다. 버튼은 최소 44px, 접근 가능한 이름과 상태를 제공한다. 패널 열기/닫기 시 초점을 관리하고 모바일에서 기존 버튼과 서명이 겹치지 않게 배치한다.

## 실패와 정리

- 키 없음: 연결을 시도하지 않고 로컬 서버 키 설정 필요 안내. 작품 감상과 음악은 계속 사용 가능.
- file 실행: 화면/음악은 사용 가능하되 실시간 음성은 로컬 서버로 여는 방법을 안내.
- 마이크 거절·장치 없음: 이해하기 쉬운 상태 표시. 재시도와 패널 종료 제공.
- 네트워크/API 오류: 비밀 값을 포함하지 않는 안내, 마이크 트랙/피어 연결/오디오 분석 노드 정리, 음악 볼륨 복원.
- 취소 후 늦게 도착한 마이크 권한/서버 응답: 세션 세대 ID로 무효화하고 새로 얻은 트랙도 즉시 중지.
- 오디오 재생 차단: 재생 재시도 버튼 제공. 들리지 않는 상태를 답변 재생 성공으로 표시하지 않음.
- 재접속은 명시적 조작만 허용하여 반복 유료 세션 생성을 방지. 대화 최대 10분 후 자동 종료하고 재시작 가능.

## 검증과 완료 판정

1. 서버: 키/비밀 파일 미노출, 잘못된 동물·SDP·origin 거절, 키 없음/업스트림 실패/타임아웃 응답을 모의 업스트림으로 검사.
2. 음성 상태: 시작→준비→발화→답변→음소거→종료, 상대 변경, 권한 대기 중 취소, 연결 중 종료와 늦은 응답, 탭 숨김 정리 검사.
3. 음악: 직접 클릭 후 오디오 컨텍스트 시작, 볼륨·감쇠·복원, 반복 켜기 중복 방지, 중지/숨김 정리 검사. 실제 청취 여부는 별도 기록.
4. 표현: 음성 크기 전달에 따른 선택 동물 강조, 움직임 줄이기에서 정지, 기존 입력 회귀 검사.
5. 브라우저: PC 4개 해상도와 모바일 390×844, 패널/버튼/크레딧 배치와 키보드 검사. 기존 오프라인 감상도 유지.
6. 실제 API: 키가 준비된 환경에서 동물별 최소 1회 한국어 음성 왕복, 말 끊기, 마이크 종료와 음악 감쇠 확인. 키/실제 마이크가 없으면 ‘실제 연결 미확인’으로 명시하며 모의 검사를 성공 대화로 보고하지 않는다.

## 비교한 방식과 선택

- 선택: Realtime WebRTC. 직접 음성 왕복과 발화 중단이 관객의 자연스러운 대화 목표에 맞는다.
- 대안: 음성 인식→텍스트 모델→음성 합성. 구성과 대기 단계가 늘어나므로 이번 구현에 사용하지 않는다.

## 공식 근거

- https://developers.openai.com/api/docs/guides/voice-webrtc — 서버에서 API 키를 사용하는 WebRTC unified 연결.
- https://developers.openai.com/api/docs/guides/realtime-conversations — 음성 대화/이벤트와 음성 선택. 첫 음성 출력 뒤에는 같은 세션의 voice를 바꿀 수 없어 상대 변경 시 새 세션을 사용한다.

문서 자기 검토: 기존 무음 사양 변경, 키 보관, 실행 방식, 상대 변경, 늦은 응답/마이크 정리, 음악 중복 방지와 검증 범위를 구체화했다. 사용자 구현 승인에 따라 제품 코드를 변경했습니다. 커밋·푸시는 하지 않았습니다.
